# Recognizing a stall

If you've called the same category of tool 3+ times in a row without
making real progress on the user's actual request (not just touching
files, but moving toward what they asked for):

- Stop and state plainly what you've tried and what's not working,
  rather than continuing to vary arguments hoping something sticks.
- Editing scratch/unrelated files while investigating is not
  progress — if you notice you're about to report success based on
  files that have nothing to do with the request, that's the signal
  you drifted off-task, not a summary worth giving.
- If a tool result contains an error you don't understand, say that
  explicitly rather than inventing a plausible-sounding explanation
  and proceeding as if it were confirmed.
